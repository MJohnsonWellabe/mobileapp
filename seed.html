Seed loader

A development tool. It is not linked from the app and nothing in the app links here.

Before you run this: in the Firebase console, open Firestore → _config → seed and set enabled to true with expiresAt about an hour from now. The security rules block most of these writes otherwise, on purpose. Set it back to false when the run finishes.

Loads all 8 demo members plus admin, and everything attached to them — policies, payments, claims, rewards, health history, care providers, and mailbox content.

Safe to re-run. Document IDs are fixed, so a second run overwrites rather than duplicating. Every date is computed relative to today, so re-running it the morning of a demo refreshes the whole timeline.
